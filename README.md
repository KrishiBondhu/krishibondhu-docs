# KrishiBondhu – Documentation Repository

Welcome to the **documentation hub** for **KrishiBondhu**, a smart agriculture technology platform designed to empower small farmers in Bangladesh.

---

## 📌 About KrishiBondhu
KrishiBondhu is an SMS and mobile-enabled platform to support farmers by:
- Providing **real-time crop prices**.
- Sending **weather alerts with crop-specific recommendations**.
- Offering **pest diagnosis and expert advice**.
- Enabling a **direct online marketplace** to connect farmers with buyers.

This repository contains all project-related documentation, research, scrum logs, and design specifications.

---

## 📂 Repository Structure
- `scrum-meetings/` → Daily Scrum meeting logs.
- `sds/` → Software Design Specification (SDS) documents.
- `research/` → Background research, market analysis.
- `diagrams/` → UML, system architecture diagrams.
- `reports/` → Weekly/monthly progress reports.
- `presentations/` → Slides and project presentations.
